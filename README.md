Used modified AffectNet dataset (modified it for only 4 emotions)
Used VGG16 (with ImageNet) for training the model
Trained for 60 epochs using fine-tuning to get 88% training accuracy and 80.9% final accuracy
Used streamlit to display the GUI of the model
Created a like/dislike system to help further personalize for each user.
